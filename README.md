## Installation et anciennes versions

Pour une mise à jour, installer la nouvelle APK par-dessus la précédente, sans désinstaller, afin de conserver les données lorsque la migration est compatible. Android peut refuser l’installation d’une ancienne version sur une plus récente. Désinstaller efface normalement les données locales : sauvegarder la progression avant un retour en arrière. Une ancienne version peut ne pas comprendre une sauvegarde récente.

Les empreintes SHA-256 sont fournies avec les releases. Les archives sont distribuées telles quelles ; elles conservent leurs anciens défauts et limitations. Les anciennes archives conservent leur binaire original ; la 0.8 est une nouvelle compilation du jeu.

Les releases proposent les APK à installer et, depuis la 0.8, un pack séparé des atlas d’animation. Le code source du jeu reste privé. Les liens automatiques « Source code » de GitHub correspondent uniquement à ce dépôt de téléchargement ; ils ne contiennent pas les sources du jeu.
